- **Primary target:** `index.html` (`css/style.css`, `js/script.js`)
- **Visitor mode:** Persuade (with interactive Operate workbench embedded for live token and specification verification)

## Audience and Job

- **Audience:** Frontend engineers, UI/UX designers, and design-systems specialists evaluating a zero-dependency static landing page and design system.
- **Visitor action:** Inspect the live light-themed design system, interact with the CSS token and specification workbench, verify responsive behavior, and copy the production `:root` token set.
