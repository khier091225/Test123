# Product

## Platform

web

## Stack

Static HTML5, CSS3, and vanilla JavaScript only (`index.html`, `css/style.css`, `js/script.js`). Zero frontend frameworks, CSS frameworks, bundlers, or external runtime dependencies.

## Users

Frontend engineers, UI/UX designers, and design-systems architects evaluating or adopting a zero-dependency static web architecture governed by deterministic quality checks (Impeccable) and anti-slop composition rules (Taste Skill). *(Inferred from explicit Master Prompt brief and repository contents.)*

## Product Purpose

Kestrel is the static reference landing page and interactive design-system workbench for this workspace. It demonstrates how pure HTML5, CSS3 custom properties, and lightweight vanilla JavaScript produce an editorial-grade, accessible, responsive light-themed web interface verified against 59 deterministic UI checks and 5 device viewports. *(Inferred from explicit Master Prompt brief.)*

## Positioning

Unlike framework-heavy templates or generic AI-generated SaaS layouts, Kestrel ships zero external runtime code while enforcing mechanical UI verification (Impeccable v4.5.2 detector) and calibrated layout variance, motion, and density dials (Taste Skill).

## Operating Context

Evaluated directly in desktop, laptop, tablet, and mobile browsers (`1440x900`, `1366x768`, `768x1024`, `390x844`, `360x800`), inspected via Playwright and Chrome DevTools, and audited locally via `.agent/skills/impeccable/scripts/impeccable.cmd detect`.

## Capabilities and Constraints

- **Confirmed capabilities:** Interactive CSS custom-property token inspector with one-click copy, architectural specification switcher (Layout, Typography, Contrast, Motion), interactive breakpoint & spacing matrix, accessible disclosure FAQ, and keyboard-accessible mobile navigation.
- **Mandatory constraints:** Pure HTML5, CSS3, and vanilla JavaScript only; mandatory light theme throughout the entire page (no dark sections, no light/dark toggle); static frontend only (no backend forms or fake submissions); zero fabricated statistics, customer counts, awards, or testimonials.

## Brand Commitments

- **Theme lock:** Modern light theme across every section, navigation bar, card, interactive surface, and footer.
- **Required CSS custom properties:** `--color-primary`, `--color-accent`, `--color-background`, `--color-surface`, `--color-text`, `--color-text-muted`, `--color-border`, `--color-primary-hover`.
- **Anti-slop discipline:** Zero em-dashes or en-dashes as separators, strict eyebrow restraint (at most 1 eyebrow per 3 sections), distinct layout families per section, single-line desktop navigation under 80px height, and one consistent CTA label per intent.

## Evidence on Hand

- Installed and active in workspace: Impeccable skill v4.5.2 (`.agent/skills/impeccable/SKILL.md`, engine v4.0.0 / v0.1.14 binary) with 59 deterministic UI detector rules.
- Installed and active in workspace: Taste Skill suite (`.agents/skills/design-taste-frontend/SKILL.md` and 12 companion skills, tracked in `skills-lock.json`).
- **Explicitly absent (must not be fabricated):** Third-party customer logos, revenue or user metrics, external awards, certifications, or customer testimonials.

## Product Principles

1. **Native browser craft over framework weight:** Use semantic HTML5, fluid CSS Grid/Flexbox, `clamp()` typography, and targeted vanilla JS event listeners instead of runtime abstractions.
2. **Mechanical verification before claims:** Every contrast ratio, breakpoint behavior, and interactive state is verified in a real headless browser and scanned with the deterministic detector.
3. **Editorial clarity in daylight:** High-contrast charcoal typography on warm alabaster and crisp white surfaces, structured by architectural hairlines and purposeful negative space.
4. **Honest static interactivity:** Every button, link, tab, and control performs a real client-side action without pretending a backend exists.

## Accessibility & Inclusion

WCAG AA contrast minimum (4.5:1 for body and form/control text, 3:1 for large display text), full keyboard navigation (`Tab`, `Enter`, `Space`, `Escape`, arrow keys for tabs), visible `:focus-visible` indicators, semantic landmarks (`header`, `nav`, `main`, `section`, `footer`), and full `prefers-reduced-motion: reduce` support.
